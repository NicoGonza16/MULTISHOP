# MULTISHOP — Laboratorio de despliegue

Interfaz académica construida con HTML, CSS y JavaScript.

## Páginas
index.html, shop.html, detail.html, cart.html, checkout.html, contact.html.

## Uso local
Abrir index.html en un navegador con conexión a internet.

## Alcance
Carrito y checkout de demostración: no procesan ventas ni pagos.
Formulario de contacto de demostración: no envía mensajes.
PHP excluido del despliegue estático con .vercelignore.
